===============================================================
 클로드코드 자동재개 — 설치 꾸러미
===============================================================

이걸 설치하면, PC 를 켤 때마다 · 인터넷이 끊겼다 돌아올 때마다
작업 폴더들이 편집기(VS Code)에서 저절로 열리고
그 안에서 claude 가 **하던 대화를 그대로 이어받는다.**


■ 설치 방법

  [맥]      설치.command  를 더블클릭
            └ "확인되지 않은 개발자" 경고가 뜨면:
              파일을 오른쪽 클릭 → 열기 → 열기
              (또는 터미널에서:  bash "install/mac/설치.sh")

  [윈도우]  설치.bat  (또는 install.bat — 같은 것) 을 더블클릭
            └ "Windows의 PC 보호" 파란 창이 뜨면:
              추가 정보 → 실행
              (또는 PowerShell 에서:
               powershell -ExecutionPolicy Bypass -File "install\win\install.ps1")

  설치할 때 폴더를 하나 물어본다.
  작업 폴더들이 들어 있는(또는 앞으로 들어갈) 폴더를 정하면 된다.
  그냥 엔터를 누르면 맥은 ~/클로드코드, 윈도우는 %USERPROFILE%\클로드코드 를 쓴다.

  관리자 권한은 필요 없다.


■ 설치하면 무슨 일이 일어나나

  정한 폴더 안에 '재시작설정' 폴더가 생기고, 거기에만 규칙이 들어간다.
  작업 폴더 하나하나에는 딱 두 가지만 심긴다.

    · .vscode/tasks.json   폴더를 열면 재시작설정을 부르는 발판
    · CLAUDE.md 의 관리 블록  "재시작 규칙은 재시작설정에만 있다"는 안내

  그리고 자동실행 2개가 등록된다.

    · 로그인할 때 한 번  → 모든 폴더를 편집기로 열고 claude 를 이어받는다
    · 인터넷 감시(상시)  → 30초 이상 끊겼다 돌아오면 되살린다

  ★ 새 작업 폴더를 만들면 다음 재개 때 자동으로 같은 규칙이 적용된다.
    (지금 바로 적용하려면 재시작설정 폴더에서
     맥: bash sync.sh    윈도우: powershell -ExecutionPolicy Bypass -File win\sync.ps1)


■ 미리 있어야 하는 것 (없어도 설치는 된다)

  · VS Code   — 없으면 터미널/새 창으로 claude 를 띄운다
  · claude    — https://claude.ai/download  또는  npm i -g @anthropic-ai/claude-code
  · 맥은 python3 (Xcode 명령줄 도구), 윈도우는 PowerShell 5 이상(기본 탑재)


■ 자주 하는 일

  손으로 전체 재시작   맥: 루트폴더의 재시작.command   윈도우: 루트폴더의 재시작.cmd
                       (윈도우에서 글자가 깨져 안 되면 재시작설정\win\재시작.cmd 를 쓴다)
  설정 고치기          재시작설정/설정.txt   (폴더 위치·시간·제외 폴더)
  한 폴더만 끄기       재시작설정/상태/<폴더이름>.끔  파일을 만든다
  전부 끄기            재시작설정/상태/.전체끔        파일을 만든다
  기록 보기            재시작설정/상태/재시작로그.jsonl
  자세한 설명          재시작설정/README.md

  제거   맥: 제거.command      윈도우: 제거.bat
         (자동실행 등록만 지운다. 작업 파일과 대화 이력은 그대로 둔다)


■ 안전에 대해

  되살아난 claude 에게 주는 첫 지시는 "읽고 점검해서 보고" 로 끝난다.
  사람이 없는 사이에 파일을 고치거나 무언가를 발행·전송하지 않는다.
  이 지시는 재시작설정/프롬프트/ 에서 폴더마다 바꿀 수 있다.
