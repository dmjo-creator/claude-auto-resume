#   · 줄 형식은  이름=값  이고, # 로 시작하는 줄은 설명이다.
#   · 값에 따옴표를 쓰지 않는다. 여러 개는 공백으로 나눈다.
#   · 고친 뒤에는 다시 설치할 필요 없다. 다음 재개 때 바로 반영된다.

# 워크스페이스들이 들어 있는 폴더. 이 폴더 **바로 아래 폴더 하나하나가 워크스페이스**다.
# 새 폴더를 만들면 다음 재개 때 자동으로 발판이 심긴다.
루트=__ROOT__

# 워크스페이스로 보지 않을 폴더 이름 (공백으로 구분). 숨김 폴더(.으로 시작)는 언제나 제외된다.
제외=data

# 자기 자신이 아니라 **그 안의 하위 폴더들**이 워크스페이스인 폴더 (묶음 폴더)
컨테이너=_bundle

# 위 규칙 밖에 있는 폴더를 더 넣고 싶을 때. 절대경로를 공백으로 구분해 적는다.
추가워크스페이스=

# --- 시간 (초) ---------------------------------------------------------------
# 부팅·복구 직후 인터넷을 기다리는 최대 시간
회선대기=300
# 편집기 창을 여는 간격. 한꺼번에 열면 편집기가 자동 작업을 흘린다
창간격=4
# 폴더를 연 뒤 자동 작업이 claude 를 띄우길 기다리는 시간
발판대기=30
# 전체 재개를 이 시간 안에 두 번 돌리지 않는다 (회선이 출렁일 때 창이 겹치는 것을 막는다)
재개간격=120
# 이 시간 이상 끊겼다 돌아와야 "복구" 로 본다
끊김최소=30
# 회선을 확인하는 간격
확인간격=20

# --- 이어받을 대화 고르기 ------------------------------------------------------
# 이 크기(바이트) 이상인 대화만 후보로 본다. 잠깐 띄운 빈 대화가 진짜 작업 대화를 가리는 것을 막는다.
최소대화크기=20000
